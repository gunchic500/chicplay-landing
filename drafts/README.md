# 약관 드래프트 보관함 (drafts)

랜딩 루트가 약관 초안으로 쌓이는 것을 막기 위한 보관 폴더입니다.
실제로 게시되는 약관은 루트의 `terms.html` / `privacy.html` 이며, 빌드 시 `dist/` 로 복사됩니다.
이 폴더의 `.md` 파일은 HTML 작성의 **소스/이력**일 뿐, 사이트에 직접 서빙되지 않습니다.

## 현재 반영본 (latest)

- **`terms_of_service_v3.md`** — 이용약관 v3 (한/영). 이벤트(입어보기 아웃핏 뽐내기 캠페인) 기능 추가 개정판.
- **`privacy_policy_v3.md`** — 개인정보처리방침 v3 (한/영). 이벤트/경품/홍보 활용·협력 브랜드 제공 반영 개정판.

위 두 v3 파일이 2026-10-21 기준으로 `terms.html` / `privacy.html` 에 반영되었습니다.
(사이트 반영 시 공고일·시행일 모두 2026-10-21 = 즉시 시행. 당시 실사용자 0명이라 사전 고지 기간 불요로 판단. 소스 파일의 날짜 자리표시자는 원문 그대로 둠.)

### 소스(.md)와 라이브(HTML)의 차이 — HTML 이 정본

- **§3 벤더 자리표시자**: 소스에는 `[외부 폼 서비스명]`·`[모바일 상품권 발송 서비스명]`·`[소재 국가]` 가 남아 있으나, 라이브 노출을 막기 위해 HTML 에서는 **해당 표 행을 삭제하고 "각 이벤트 진행 시 참여·동의 화면에서 개별 고지·동의" 문구로 대체**했습니다(한/영). 벤더 확정 시 표 행 복원 여부를 결정하세요.
- **개인정보 보호책임자 이메일**: 소스는 `privacy@chicplay.net`, 라이브 HTML 은 `ghk@chicplay.net` 로 통일했습니다.
