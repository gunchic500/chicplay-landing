# 약관 드래프트 보관함 (drafts)

랜딩 루트가 약관 초안으로 쌓이는 것을 막기 위한 보관 폴더입니다.
실제로 게시되는 약관은 루트의 `terms.html` / `privacy.html` 이며, 빌드 시 `dist/` 로 복사됩니다.
이 폴더의 `.md` 파일은 HTML 작성의 **소스/이력**일 뿐, 사이트에 직접 서빙되지 않습니다.

## 현재 반영본 (latest)

- **`terms_of_service_v3.md`** — 이용약관 v3 (한/영). 이벤트(입어보기 아웃핏 뽐내기 캠페인) 기능 추가 개정판.
- **`privacy_policy_v3.md`** — 개인정보처리방침 v3 (한/영). 이벤트/경품/홍보 활용·협력 브랜드 제공 반영 개정판.

위 두 v3 파일이 2026-10-21 기준으로 `terms.html` / `privacy.html` 에 반영되었습니다.
(사이트 반영 시 시행일 2026-10-28 / 공고일 2026-10-21 로 기재. 소스 파일의 날짜 자리표시자는 원문 그대로 둠.)

> ⚠️ v3 개인정보처리방침 §3(처리위탁·국외이전) 표에는 아직 확정되지 않은 자리표시자가 있습니다:
> `[외부 폼 서비스명]`, `[모바일 상품권 발송 서비스명]`, `[소재 국가]`.
> 이벤트/경품 운영 벤더가 확정되면 HTML과 이 소스 양쪽을 함께 갱신해야 합니다.
